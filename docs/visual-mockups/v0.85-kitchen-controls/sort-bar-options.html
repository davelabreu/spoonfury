How the sort options work

  • Newest (default) — current behavior, by created_at descending
  • A-Z — alphabetical by title
  • Category — groups recipes by their category, alphabetically within each
  • Cuisine — groups by cuisine tag (e.g. Italian, Mexican, Asian)
  • Lifestyle — groups by lifestyle tag (e.g. Vegetarian, Quick & Easy)

Category/Cuisine/Lifestyle would group recipes with a subtle label divider between groups. Recipes with no matching tag land in an "Other" bucket at the bottom.
